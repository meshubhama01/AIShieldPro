This Week's Signal

The evolving sophistication of agentic frameworks and their interaction with external data sources presents a growing attack surface, demanding deeper inspection of both LLM behavior and the middleware facilitating agentic actions.

Jailbreak & Prompt Injection

RedDarwin: Evolving Jailbreak Skills against Frontier LLMs

This research introduces RedDarwin, an agentic framework that treats attack skills, not just prompts, as evolutionary units. By autonomously revising, composing, and selecting skills based on target model feedback, it demonstrates a significant leap in adaptive jailbreaking capabilities. Practitioners should anticipate more dynamic and resilient prompt injection attacks that learn and adapt in real-time.

Source: arXiv cs.CR | October 19, 2026

Jailbreak & Prompt Injection

Identify, Classify, Act: Per-Instruction Controlled Compliance for LLMs over External Data

This paper addresses the critical challenge of LLMs processing external data that may contain interleaved legitimate instructions and prompt injections. The proposed EDIC framework enables per-instruction credit attribution, allowing models to differentiate and act on individual directives. This highlights the need for granular control and validation of LLM outputs when interacting with untrusted external information sources.

Source: arXiv cs.CR | October 19, 2026

Jailbreak & Prompt Injection

Ignored, Not Refused: What Low Prompt-Injection Success Rates Hide in Small Tool-Using Agents

This study reveals that low reported prompt injection success rates in tool-using agents often mask a higher prevalence of "ignored" attacks rather than outright refusals. This implies that even if an attack doesn't immediately succeed, the agent may not be robustly handling malicious instructions, leaving potential vulnerabilities. System prompt configurations significantly impact this behavior, underscoring the importance of rigorous testing beyond simple success/failure metrics.

Source: arXiv cs.CR | October 19, 2026

MCP & Agentic Threats

GatewayBench: Unified Capability and Security Evaluation Platform for MCP Gateways

The introduction of GatewayBench addresses a critical gap in evaluating Model Context Protocol (MCP) gateways, the middleware connecting AI agents to tools. As these gateways become central to agentic systems, their design directly impacts capability, efficiency, and security. Organizations deploying agents should prioritize evaluating their MCP gateway implementations for potential security weaknesses and capability limitations.

Source: arXiv cs.AI | October 19, 2026

MCP & Agentic Threats

What It Is, Not What It Says: Securing Agentic Browsing Interactions with Web Semantics

This paper proposes Intact, a system that enhances agentic web browsing by preserving web semantics and provenance. By representing webpages in a GenTree structure, it aims to prevent LLMs from being misled by injected text that exploits the difference between an element's appearance and its actual function. This is crucial for securing agents that interact with the web, as it moves beyond simple text parsing to understanding the integrity of the information consumed.

Source: arXiv cs.CR | October 19, 2026

MCP & Agentic Threats

How Agents Ask for Permission: User Permissions for AI Agents, from Interfaces to Enforcement

This research surveys user-level permission systems for AI agents, highlighting significant gaps in usability, transparency, and user control despite numerous proposals. As agents become more integrated into workflows, the lack of robust, user-centric permission management presents a substantial security and privacy risk. Organizations must focus on implementing granular, user-aware permission controls for agentic actions.

Source: arXiv cs.CR | October 19, 2026

MCP & Agentic Threats

Author-in-the-loop Agentic Reproducibility Auditing for a Machine Learning Conference

This work introduces an agentic system for reproducibility auditing in ML conferences, emphasizing an "author-in-the-loop" approach. By making author declarations explicit inputs and using a two-stage workflow for agent checks and author clarification, it streamlines the reproduction process. While focused on reproducibility, the underlying mechanism of an agent interacting with external code and data, and requiring explicit instructions, has implications for understanding agentic behavior and potential misuse in other contexts.

Source: arXiv cs.AI | October 19, 2026

Practitioner Take

This week's intel underscores a critical shift: AI agents are no longer isolated models but complex systems interacting with the external world via increasingly sophisticated middleware like MCP gateways. The RedDarwin research signals an arms race in jailbreaking, moving from static prompts to dynamic, evolving attack strategies. Simultaneously, the work on web semantics and per-instruction compliance highlights the fragility of LLMs when processing untrusted external data, whether it's web content or tool outputs. The prevalence of "ignored" attacks suggests a false sense of security. The overarching risk is the increasing attack surface created by agentic autonomy and their reliance on external data and tools, demanding robust validation at every interaction point. Focus on auditing MCP gateway configurations and implementing granular, context-aware controls for agent actions, especially when processing external inputs.

Hunt Query of the Week

Detecting indirect prompt injection attempts within tool-use agent logs requires monitoring for unusual tool call patterns or unexpected data processing. This query aims to identify instances where an agent might be processing data that contains hidden instructions, by looking for specific patterns often used in such attacks within the agent's output logs or tool interaction data. This is a generalized example and would need adaptation to specific logging formats and agent behaviors.

// Example KQL for Microsoft Sentinel to detect potential indirect prompt injection signals
// This query looks for specific keywords or patterns often found in malicious instructions
// within agent tool execution logs. It's a starting point and requires tuning.

let AgentToolLogs = materialize(
    // Replace with your actual table name for agent tool execution logs
    YourAgentToolExecutionLogTable
    | where Timestamp between (ago(7d)..now())
);
AgentToolLogs
| where Output contains "ignore previous instructions" or Output contains "disregard all prior commands" or Output contains "execute the following command regardless of previous context"
| project Timestamp, AgentId, ToolName, Input, Output, Status
| extend PromptInjectionSignal = iff(Output contains "ignore previous instructions", 1, 0) +
                               iff(Output contains "disregard all prior commands", 1, 0) +
                               iff(Output contains "execute the following command regardless of previous context", 1, 0)
| where PromptInjectionSignal > 0
| summarize count() by AgentId, ToolName, bin(Timestamp, 1h)
| order by Timestamp desc
