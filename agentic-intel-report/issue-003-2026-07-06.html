This Week's Signal

Multiple reports of AI agents being exploited to conduct ransomware attacks and evade security scanners highlight the growing threat of agentic AI in cyber attacks.

MCP & Agentic Threats

MCP Authentication Bypass via OAuth2 Passthrough Fallback

LiteLLM's MCP Streamable HTTP endpoint was vulnerable to an authentication bypass, allowing an unauthenticated attacker to establish an authenticated MCP session using an arbitrary Bearer token. This vulnerability has been patched in version 1.84.0. Practitioners should upgrade to the latest version or disable MCP routes as a workaround.

Source: GitHub Advisory (BerriAI/litellm) | July 06, 2026

AI Agent Exploits Langflow RCE to Automate Database Ransomware Attack

A security firm reported the first ransomware attack run from start to finish by an AI agent, which exploited a Langflow RCE vulnerability to automate the attack. This demonstrates the potential for AI agents to automate complex, multi-stage intrusions. Practitioners should be aware of the growing threat of agentic AI in cyber attacks.

Source: The Hacker News | July 06, 2026

Agentic AI Used to Conduct Ransomware Attack via Langflow

A ransomware attack was conducted using an agentic AI agent, which combined known exploitation techniques with real-time reasoning to automate the attack. This highlights the potential for AI agents to be used in complex, multi-stage intrusions.

Source: SecurityWeek | July 06, 2026

SkillCloak Lets Malicious AI Agent Skills Evade Static Scanners with Self-Extracting Packing

A new technique called SkillCloak allows malicious AI agent skills to evade static scanners using self-extracting packing. This technique was found to be effective in evading scanners, highlighting the need for runtime checkers to detect malicious skills.

Source: The Hacker News | July 06, 2026

Fake Bug Report Hijacks AI Coding Agents at Scale

A fake bug report was used to hijack AI coding agents at scale, demonstrating the ease with which attackers can exploit an AI agent's inability to differentiate between content and instructions. Practitioners should be aware of the potential for AI agents to be hijacked using social engineering tactics.

Source: Dark Reading | July 06, 2026

Jailbreak & Prompt Injection

Critical Cursor Flaws Could Let Prompt Injection Escape Sandbox and Run Commands

Two flaws in the Cursor AI code editor could allow a prompt injection attack to escape the editor's safety sandbox and run any command on a developer's computer. Practitioners should be aware of the potential for prompt injection attacks to be used in conjunction with other exploits.

Source: The Hacker News | July 06, 2026

Practitioner Take

This week's signals highlight the growing threat of agentic AI in cyber attacks, with multiple reports of AI agents being exploited to conduct ransomware attacks and evade security scanners. Practitioners should be aware of the potential for AI agents to automate complex, multi-stage intrusions and take steps to prevent AI agent hijacking and prompt injection attacks. One concrete defensive posture is to implement runtime checkers to detect malicious AI agent skills and monitor for suspicious activity.

Hunt Query of the Week

To detect potential AI agent hijacking and prompt injection attacks, practitioners can use the following KQL query in Microsoft Sentinel:

SecurityEvent
| where EventID == 4688
| where CommandLine contains "curl" or CommandLine contains "wget"
| where CommandLine contains "http" or CommandLine contains "https"
| summarize count() by bin(Timestamp, 1h)
