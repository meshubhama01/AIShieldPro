Hunt Query of the Week

Detecting unauthorized agentic tool usage or data exfiltration from isolated environments is critical. This KQL query in Microsoft Sentinel looks for unusual patterns of API calls to external services originating from compute instances that should not be making such calls, potentially indicating an agent attempting to communicate or exfiltrate data.

SecurityEvent
| where EventID == 4624 // Successful Logon
| where AccountType == "User" and AccountName !startswith "System$" and AccountName !startswith "Network Service"
| join kind=inner (
    SecurityEvent
    | where EventID == 4688 // Process Creation
    | where NewProcessName has_any ("powershell.exe", "cmd.exe", "python.exe", "node.exe")
    | extend CommandLineArgs = CommandLine
    | where CommandLineArgs has_any ("curl", "wget", "Invoke-RestMethod", "Invoke-WebRequest")
    | extend TargetUrl = extract(@"https?://[^/\s]+", 1, CommandLineArgs)
    | where isnotempty(TargetUrl) and TargetUrl !startswith "127.0.0.1" and TargetUrl !startswith "localhost"
    | extend Domain = split(TargetUrl, '.')[1] // Basic domain extraction for common TLDs
    | where Domain !in ("microsoft.com", "google.com", "yourcompany.com") // Exclude known safe domains
    | project Computer, ProcessName, CommandLineArgs, TargetUrl, Domain, InitiatingProcessName, InitiatingProcessCommandLine
) on $left.Computer == $right.Computer and $left.AccountName == $right.AccountName
| project TimeGenerated, Computer, AccountName, ProcessName, CommandLineArgs, TargetUrl, InitiatingProcessName, InitiatingProcessCommandLine
| summarize count() by Computer, AccountName, TargetUrl, Domain, bin(TimeGenerated, 1h)
| where count_ > 2 // Threshold for suspicious activity within an hour
