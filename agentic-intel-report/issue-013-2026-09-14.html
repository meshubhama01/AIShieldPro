Practitioner Take

Hunt Query of the Week

Detecting anomalous AI agent activity requires monitoring for unusual tool invocation patterns and data exfiltration. This query hunts for suspicious PowerShell execution sequences often associated with automated reconnaissance and exploitation frameworks.

DeviceProcessEvents
| where FileName =~ "powershell.exe"
| where ProcessCommandLine has_any ("Invoke-WebRequest", "Invoke-RestMethod", "Get-Content", "Set-Content", "Invoke-Command", "IEX")
| summarize count() by DeviceName, InitiatingProcessFileName, InitiatingProcessCommandLine, FolderPath, FileName, ProcessCommandLine, bin(Timestamp, 1h)
| where count_ > 5 // Threshold for suspicious activity, adjust as needed
| project Timestamp, DeviceName, InitiatingProcessFileName, InitiatingProcessCommandLine, FolderPath, FileName, ProcessCommandLine, count_
