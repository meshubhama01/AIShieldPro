Mandato addresses a critical gap in AI agent security by introducing protocol-level enforcement of digitally signed mandates for tool usage. Agentao: A Governed Local-First Runtime for Tool-Using LLM Agents

Agentao proposes a layered runtime architecture to govern LLM agents that invoke tools and manage local state. By separating action proposals from host-authorized execution, it aims to mitigate risks like prompt injection, tool poisoning, and uncontrolled side effects. This is a key development for securing the execution environment of increasingly capable agents.

Hunt Query of the Week

Detecting unauthorized tool usage by AI agents often requires deep inspection of network traffic and execution logs. The following KQL query for Microsoft Sentinel aims to identify suspicious outbound network connections from common AI/ML service endpoints that might indicate unauthorized data exfiltration or command-and-control activity. This query looks for connections to non-standard ports or unusual destinations originating from hosts running AI workloads.

SecurityEvent
| where EventID == 3 // Network Connection Event
| extend Protocol = tostring(split(parse_json(JsonProperties).Protocol, '/')[0])
| extend RemoteIP = tostring(split(parse_json(JsonProperties).RemoteAddress, ':')[0])
| extend RemotePort = toint(split(parse_json(JsonProperties).RemoteAddress, ':')[1])
| where Protocol =~ "TCP"
| where RemotePort !in (80, 443, 22, 3389) // Exclude common legitimate ports
| join kind=inner (
    DeviceNetworkEvents
    | where Action == "SYN" and InitiatingProcessFolderPath has_any ("python.exe", "powershell.exe", "cmd.exe") // Heuristic for AI/scripting processes
    | extend InitiatingProcessName = tostring(split(InitiatingProcessFolderPath, '\\')[-1])
    | project DeviceName, InitiatingProcessName, InitiatingProcessFolderPath
) on $left.DeviceName == $right.DeviceName
| project TimeGenerated, DeviceName, InitiatingProcessName, InitiatingProcessFolderPath, RemoteIP, RemotePort, Protocol
| summarize count() by DeviceName, InitiatingProcessName, RemoteIP, RemotePort, Protocol
| where count_ > 2 // Threshold for suspicious activity
